## 💫 About Me

I am an AI/ML Engineer and Data Scientist focused on building intelligent agentic architectures, deep learning sequence models, and AI-first web applications. My work spans from natural language processing and advanced text summarization to multi-agent automated research workflows.

* 🧠 **Generative AI & Agents:** Designing multi-agent systems with citation tracing, contradiction detection, and context-aware LLM application backends.
* 📊 **Deep Learning & NLP:** Building and training RNNs and LSTMs for complex sequence tasks like sentiment analysis and sensor-based activity recognition.
* 🕸️ **AI-First Web Applications:** Integrating state-of-the-art open-source intelligence (LLaMA 3, Ollama, LangChain) with robust production frameworks like Flask and Streamlit.
